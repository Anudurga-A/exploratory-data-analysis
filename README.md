# Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a student performance dataset using Python. It analyzes study hours, attendance, and student marks to identify meaningful patterns in the data.

## 🎯 Objective
To explore, clean, analyze, and visualize student performance data using Python libraries.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Tasks Performed
- Created and explored a student performance dataset.
- Displayed the first five rows of the dataset.
- Analyzed dataset structure and statistical summaries.
- Checked missing values and duplicate records.
- Created four visualizations.
- Identified five observations from the dataset.
- Saved the cleaned dataset as a CSV file.

## 📈 Visualizations
1. Histogram – Distribution of Student Marks
2. Bar Chart – Student-wise Marks
3. Scatter Plot – Study Hours vs Marks
4. Box Plot – Distribution of Student Marks

## 🔍 Key Observations
1. The dataset contains 10 students.
2. Student marks range from 45 to 95.
3. Students who study more hours generally score higher marks in this sample dataset.
4. Student attendance ranges from 60% to 98%.
5. The dataset contains no missing values or duplicate rows.

## 📁 Project Files
- `EDA.ipynb` – Jupyter Notebook containing the analysis.
- `cleaned_student_performance.csv` – Cleaned dataset.
- `README.md` – Project documentation.
